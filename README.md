## Introduction
DrosmazTheme is my personal [Obsidian](https://obsidian.md) theme.
Currently it's a work in progress, and it only have the dark theme (probably i will never make the light one, i would never use it anyway).

If you have found this theme you can use it however you want to, but just known that i have made it for a personal use and i don't really care if you like it or not.

## Installation

### Obsidian MarketPlace
Install the theme directly from the **settings** of obsidian, following this _steps_:
1. Open **settings** and navigate on **apparances**;
2. Click the **manage** button in the **themes** section;
3. Search "DrosmazTheme" in the search bar and click **use**;

### Manual
1. Download this repository and copy the 'theme.css' file in the vault's directory: '/.obsidian/themes';
2. Now you can rename the file however you like (best thing would be renaming it 'DrosmazTheme';
3. Go in the **apparances** field and select the theme from the list;
